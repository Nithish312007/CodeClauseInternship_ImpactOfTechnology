# The Impact of Technology on Everyday Life

## 📌 Project Overview
This project discusses how technology influences everyday life.
It explains both the positive and negative impacts of technology
on communication, education, work culture, and lifestyle.

This project is created as part of the **CodeClause Internship – Content Writer Intern**.

## 🎯 Objective
The main objective of this project is to:
- Explain the role of technology in daily life
- Highlight advantages and disadvantages
- Create awareness about balanced technology usage
